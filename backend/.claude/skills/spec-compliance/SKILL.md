# SPEC compliance — антифрод-утилита

Источник истины: `ScamTest/SPEC.md`. Этот файл — вытяжка, при любом сомнении
перечитать сам SPEC.md, а не полагаться только на вытяжку.

## Три результата (имена копировать дословно, не перефразировать)

- `"Подмена не обнаружена"` — ни один из 5 сценариев не сработал.
- `"Есть подозрение"` — сработал только сценарий 7.5, среди 7.1–7.4 (что
  выполнились) подмены нет.
- `"Обнаружена подмена"` — сработал хотя бы один из 7.1–7.4, независимо от 7.5.

Плюс отдельное техническое сообщение (не четвёртый статус):
`"Проверка выполнена не полностью"` — когда хотя бы одна из 5 проверок не
выполнена технически.

## 5 сценариев (§7)

| # | Условие | Результат при срабатывании |
|---|---|---|
| 7.1 | адрес на странице ≠ адрес в QR-коде | Обнаружена подмена, показать оба значения |
| 7.2 | значение для копирования по кнопке ≠ отображённый адрес (только клик по кнопке, не выделение/хоткеи/системный буфер) | Обнаружена подмена, показать оба значения |
| 7.3 | адрес меняется в течение 5 секунд после запуска проверки | Обнаружена подмена, указать что изменился после старта |
| 7.4 | сумма и/или сеть в QR ≠ сумма/сеть на странице | Обнаружена подмена, указать какой параметр (сумма/сеть/оба) |
| 7.5 | подключён скрипт не из разрешённого списка | Есть подозрение (слабее, не «подмена»), указать какой скрипт |

## Правила приоритета (§8) — самое частое место ошибок

1. Один запуск проверяет все 5 сценариев за раз, формирует один основной
   результат.
2. Если среди **завершённых** сценариев есть подмена (7.1–7.4) → показать
   «Обнаружена подмена» первым, независимо от 7.5.
3. Если подмены нет, но сработал 7.5 → «Есть подозрение».
4. Если хотя бы одна из 5 проверок не выполнена технически:
   - «Подмена не обнаружена» показывать **нельзя** ни при каких условиях;
   - «Проверка выполнена не полностью» указывает, какая именно проверка (или
     какие) не завершена;
   - если по завершённым проверкам уже есть «Обнаружена подмена» или «Есть
     подозрение» — техническое сообщение идёт **рядом**, не заменяет и не
     скрывается;
   - если по завершённым проверкам ни подмены, ни 7.5 не найдено — техническое
     сообщение показывается самостоятельно.
5. Результат «Обнаружена подмена»/«Есть подозрение» всегда называет, какой
   именно сценарий сработал (все сработавшие, если больше одного), и в чём
   расхождение — со значениями, где применимо.
6. Утилита никогда не блокирует и не выполняет перевод сама — только
   показывает результат. Перевод остаётся доступен при любом результате.
7. Никаких категоричных формулировок: «гарантирует», «полностью защищает»,
   «находит любое мошенничество» и синонимичные — запрещены в любом
   пользовательском тексте.

## Критерии приёмки (§9) — 1:1 маппинг на тесты Агента D

Каждый пункт §9 SPEC.md — отдельный тест: срабатывание/несрабатывание каждого
из 5 сценариев по отдельности, покрытие всех пяти за один запуск, оба случая
частичного сбоя (с обнаруженной подменой и с подозрением), отсутствие
категоричных формулировок, доступность перевода при любом результате.
