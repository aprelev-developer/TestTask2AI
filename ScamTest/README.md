# Антифрод-утилита для криптоплатёжных страниц

Продуктовая документация и материалы аналитической части проекта.

## Идея продукта

Небольшая демонстрационная утилита (MVP), которую пользователь запускает
вручную на локальной тестовой странице криптооплаты. Утилита проверяет пять
заранее заданных технических сценариев подмены платёжных данных (адрес в
QR-коде, подмена при копировании, изменение адреса после запуска проверки,
несовпадение суммы/сети, неразрешённый скрипт на странице) и предупреждает
пользователя одним из трёх результатов до того, как он переведёт средства.

Все реквизиты и операции тестовые. Реальные средства и блокчейн не
используются. Продукт не определяет репутацию владельца кошелька и не
обещает находить все виды мошенничества.
